# Meet Secure Core — Media Layer Roadmap
**Version:** 0.1.0-draft | **Date:** 2026-08-31 | **Author:** @webrtc | **Status:** Pending Review

---

## 1. SFU Routing Strategy

**Simulcast + SVC (H.264/VP9/AV1)** — Each sender publishes 3 spatial layers (180p/360p/720p) + 2 temporal layers per spatial. SFU (LiveKit) selects layer per subscriber based on `REMB`/`transport-cc` feedback.

**Dynacast / Last-N** — Active speaker + recent-N (configurable N=9 default) receive high layer; others get base layer (180p @ 15fps). Page-in on pin/hover. Reduces downlink 60-80% at 20-100 participants.

**Bandwidth Adaptation** — Server-side `transport-cc` + client-side `REMB`. SFU re-writes RTP extmap `abs-send-time` → `transport-cc`. On congestion: drop high temporal → drop high spatial → pause video (audio only). PLI/NACK forwarded selectively to sender.

**Scalability Targets:**
| Mode | Participants | SFU Nodes | Downlink/Viewer |
|------|-------------|-----------|-----------------|
| 1:1 P2P | 2 | 0 | ~1.5 Mbps |
| Small group | ≤20 | 1 | ~2.5 Mbps (720p) |
| Large group | 20-100 | 3-5 (cascade) | ~2.5 Mbps |
| Webinar | 1000 | 8-10 (fan-out) | ~1.8 Mbps (recvonly) |

## 2. E2EE Implementation Details

**SFrame (RFC 9605) via Insertable Streams / WebRTC Encoded Transform** — Per-frame encryption *after* encoder, *before* packetization. SFU forwards opaque ciphertext; no decode/mix possible. Keys never touch server.

**Key Sharing** — MLS (RFC 9420) over DataChannel. Each participant holds `GroupContext` + `EpochSecret`. On join: `Welcome` message via signaling (encrypted to joiner's HPKE key). Rotation: `Commit` on leave/join, pushed via DataChannel. Key schedule: `sender_key = HKDF(epoch_secret, "sframe", sender_id)`.

**Compatibility with Forwarding** — SFrame header (KID, CTR) preserved in RTP payload. SFU inspects only `ssrc`/`mid` for routing. Key rotation sync via `keyframe-request` + DataChannel ack.

**Fallback** — If Insertable Streams unavailable (Safari <17, Firefox <115): WASM `wasm-sframe` worker in `OffscreenCanvas` path. Slightly higher latency (~15ms), same security.

## 3. P2P ↔ SFU Handoff & ICE Restart

**Negotiation** — Signal `p2pPreferred: true` for 1:1. Both peers gather ICE, attempt direct connection. 10s timeout → SFU fallback.

**Handoff Triggers:**
- 3rd participant joins → SFU `recvonly` from both, then `sendrecv` via SFU
- ICE failure / TURN required for >5s
- Explicit `elevateToSFU()` from UI (record, transcribe)

**ICE Restart Handling:**
1. SFU sends `session-update` with new `ice-ufrag`/`ice-pwd` via signaling
2. Client `setLocalDescription` → new offer with `ice-restart`
3. Parallel DTLS (keep existing) + new ICE gathering
4. On success: `setRemoteDescription` → seamless switch (no media gap)
5. SFrame keys unchanged (epoch preserved)

**State Sync** — Redis tracks `p2pState: "direct" | "sfu" | "transitioning"`. Rejoin logic reuses epoch keys.

## 4. TURN/STUN Scaling & Fallback

**Deployment** — `coturn` cluster behind Anycast/GeoDNS. 3 regions minimum (US, EU, APAC). Each node: 8 vCPU, 32GB, 10 Gbps NIC. Capacity: ~5000 concurrent relays.

**Credentials** — HMAC-SHA256 ephemeral (`turn:timestamp:username:hmac`), TTL 24h. Generated by `meet-signal` on join. No long-term credentials stored.

**Fallback Chain:**
1. STUN (direct) → 2. TURN UDP → 3. TURN TCP (443) → 4. TURN TLS (443) → 5. SFU relay via TURN (last resort)

**Monitoring** — `coturn` stats → Prometheus: `relayed_bytes`, `allocation_failures`, `tcp_pressure`. Alert at >70% capacity. Auto-scale via K8s HPA on `turn_allocations_active`.

**Privacy** — Logs: timestamp, realm, allocated IP (no user-agent, no roomId). Retention 24h. IP hash-salted in metrics.

## 6. Risks & Fallbacks

| Risk | Likelihood | Impact | Mitigation / Fallback |
|------|------------|--------|----------------------|
| **Codec Negotiation Failure** (VP9/AV1/H264 mismatch) | Medium | High (no media) | Mandate H.264 baseline + VP9. SDP munging: prefer `H264/90000` then `VP9/90000` then `AV1/90000`. Transcoder `meet-composer` only for PSTN/recording (opt-in). |
| **Insertable Streams Unavailable** (Safari/Firefox old) | High (initial) | Medium | WASM `wasm-sframe` worker polyfill. Bundle size +150KB. Test matrix: Chrome 108+, Firefox 115+, Safari 17+, Edge 108+. |
| **Mobile Battery Drain** (encoding 3 layers) | High | High | Adaptive encoding: drop to 2 spatial + 1 temporal on battery saver / thermal throttle. `requestVideoFrameCallback` for frame pacing. Background tab → pause video send. |
| **SFU Cascading Latency** (>300ms cross-region) | Medium | Medium | Geo-affinity: `roomId` → nearest SFU pool. Client hints `preferRegion` in join. WebRTC `googCpuOveruseDetection` for local adaptation. |
| **MLS Key Rotation Deadlock** (large group rekey) | Low | High | Batch commits (max 50/epoch). Async `Welcome` via signaling (not DataChannel) for >50. Fallback: central KMS epoch key (audit-logged). |
| **TURN Exhaustion** (DDoS / flash crowd) | Medium | High | Per-IP rate limit (10 alloc/min). CAPTCHA on allocation failure >3. Priority queue: P2P > SFU > TURN. Emergency: disable video, audio-only via TURN. |
| **Recording Key Compromise** | Low | Critical | Client-side envelope encryption: `recording_key = HKDF(master, "rec", roomId)`. Server stores only wrapped key. Rotation per segment (5min). |
